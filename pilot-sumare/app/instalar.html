Instalar O Empregador Online

A instalação é feita pelo navegador. Se o botão abaixo estiver indisponível, use o menu do Chrome ou Safari seguindo os passos logo abaixo.

Use o passo a passo abaixo. A opção Instalar fica no menu do navegador quando não há janela automática.

Android — pelo Chrome

  1. Abra este endereço diretamente no Google Chrome.
  2. Toque nos três pontos ⋮, ao lado da barra de endereço.
  3. Toque em Instalar e criar atalho e depois em Instalar. Em outras versões, procure Instalar aplicativo ou Adicionar à tela inicial.
  4. Confirme a opção apresentada. Depois procure Empregador entre seus aplicativos ou na tela inicial.

Se aparecer somente Criar atalho, essa opção adiciona o acesso à tela inicial; ela não confirma uma instalação completa. Confira também se o app já está instalado.

iPhone ou iPad — pelo Safari

  1. Abra este endereço diretamente no Safari.
  2. Toque em Compartilhar, o quadrado com seta para cima.
  3. Escolha Adicionar à Tela de Início. Se aparecer Abrir como App da Web, mantenha ativado.
  4. Confirme em Adicionar e abra pelo novo ícone.

Abriu dentro de outro aplicativo?

Se chegou pelo WhatsApp, Instagram ou outro aplicativo, use o menu dele para Abrir no navegador. Se essa opção não aparecer, copie o endereço abaixo e cole no Chrome ou Safari.

O app usa a mesma conta e precisa de internet para consultar e salvar seus dados. Não é necessário baixar APK.
